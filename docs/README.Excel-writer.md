This tool takes input and updates an Excel table that tracks different job application entries.

The user can add an entry, which will have been copied to the clipboard. It will contain the text of the source paragraph and a link to the source paragraph. The link contains two URLs, one for the online version of the notebook, and one for the local version of the notebook; the local version will be used to add a hyperlink to the text of the source paragraph. When the user clicks on the hyperlinked cell, Excel will send the user to the appropriate paragraph in OneNote.
